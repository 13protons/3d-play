Coordinate System — The Key Insight
THE PROBLEM:
  Sun to Neptune ≈ 4.5 × 10¹² meters
  A spacecraft part ≈ 0.01 meters
  That's ~15 orders of magnitude

  JavaScript numbers (float64): ~15-16 significant digits  ✓ OK for simulation
  GPU floats (float32):         ~7 significant digits       ✗ Jitter at large distances

THE SOLUTION: Floating-origin, camera-relative rendering

  ┌─ SIMULATION (float64, in worker) ──────────────────────────────┐
  │                                                                 │
  │  Sun:    [0, 0, 0]                                             │
  │  Earth:  [1.496e11, 0, 0]          ← real distances in meters  │
  │  Moon:   [1.4964e11, 0, 0]                                     │
  │  Craft:  [1.4960002e11, 3.5, 0]    ← near Earth surface        │
  │                                                                 │
  └─────────────────────────────────────────────────────────────────┘
                    │
                    │  floatingOrigin = craft position
                    │  renderPos = simPos - floatingOrigin
                    ▼
  ┌─ RENDERING (float32, on GPU) ──────────────────────────────────┐
  │                                                                 │
  │  Sun:    [-1.496e11, 0, 0]    ← big but far away, precision    │
  │  Earth:  [-2e4, 0, 0]             doesn't matter for distant   │
  │  Moon:   [4e5, 0, 0]              objects — they're small       │
  │  Craft:  [0, 3.5, 0]         ← near origin, full precision ✓  │
  │                                                                 │
  └─────────────────────────────────────────────────────────────────┘

  Everything close to the camera has small coordinates → no jitter.
  Everything far away has big coordinates but is tiny on screen → jitter invisible.
