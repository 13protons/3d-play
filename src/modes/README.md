# Game Modes

Top-level screens that compose rendering and UI for each mode.

See [notes/09-game-modes.md](../../notes/09-game-modes.md) for the mode architecture.

## Modes

- `Flight.tsx` — Simulation view (Scene + HUD overlay, primary gameplay)
- `MapView.tsx` — Orbital map (future, toggleable over Flight)
- `Editor.tsx` — Part assembly / vehicle building (future)
